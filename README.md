# Furry Hearts of Jordan — website

The website for furryheartsofjordan.com.

## Updating the site (every day)
Go to **https://furryheartsofjordan.com/admin** and sign in with GitHub.

- **Rescues · الحيوانات**: add a new rescue, change a status (Available / In treatment / Reserved / Adopted), add photos, reels, tests, receipts and travel papers.
- **Site content → Pet Taxi rides**: add a ride at the top. Tick **Paid ✓** when the screenshot arrives.
- **Site content → CliQ accounts / Happy tails / Settings & links**.

Press **Publish**. The website updates by itself in about 1 minute.

## Where things are
| Folder | What is inside |
|---|---|
| `content/rescues/` | One file per rescue (kai.json, patchi.json…) |
| `content/` | Rides, CliQ accounts, happy tails, settings, care guide |
| `img/` | Photos and illustrations. New uploads go to `img/uploads/` |
| `fonts/` | Put the brand font files here (see below) |
| `admin/` | The admin page |

## Brand fonts
Upload these files into the `fonts` folder with exactly these names:
`PestaRakyat.otf` (titles), `GTWalsheim-Light.woff2`, `GTWalsheim-Regular.woff2`, `GTWalsheim-Medium.woff2`.
GT Walsheim needs a web licence. Until the files are there, the site uses Bagel Fat One and Figtree.

## Privacy
Never upload home, clinic or boarding locations, private phone numbers, or receipts with personal details that are not blurred.
